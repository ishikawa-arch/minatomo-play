## 2. 検出した問題と判断結果

### E-1. 「診察応接集中全般（感情接試誤発ケース）」

意味不明の日本語。「診察応接集中」「感情接試誤発」とも語として成立していない。

| 項目 | 内容 |
|---|---|
| **修正前** | `診察応接集中全般（感情接試誤発ケース）` |
| **修正後** | `心理的サポート体制が確保されていない環境での単独使用（感情誘発リスク）` |
| **判断理由** | 元の意図は「心理サポートが必要な感情系ゲームの単独使用への注意」だった。意図を明確化した文言に置換。 |

**影響箇所:**

- `games-catalog.json` 行 2468 (`games[].contraindications.avoid`)
- `games-catalog.json` 行 3401 (`games[].contraindications.avoid`)
- `scripts/apply_contraindications.py` 行 102 (`PATTERNS["P7"]["avoid"][2]`)

→ catalog 2 箇所 + script 1 行

---

### E-2. 「認知症で遮心不安・心理不安が高評価される方」

「遮心」は語として存在せず、「高評価される」も文脈と合わない。

| 項目 | 内容 |
|---|---|
| **修正前** | `認知症で遮心不安・心理不安が高評価される方` |
| **修正後** | `認知症で焦燥不安・心理的不安が強い方` |
| **判断理由** | BPSD の臨床用語「焦燥不安」が正解。「心理不安」→「心理的不安」、「高評価される」→「強い」で自然な日本語に。 |

**影響箇所:**

- `games-catalog.json` 行 2473 (`games[].contraindications.cautions`)
- `games-catalog.json` 行 3407 (`games[].contraindications.cautions`)
- `scripts/apply_contraindications.py` 行 105 (`PATTERNS["P7"]["cautions"][0]`)

→ catalog 2 箇所 + script 1 行

### F-1. 「避難・充電・守秘等」

「充電」は文字化け。本来「急変」だった可能性が高い。さらにベースライン禁忌として現場のさまざまな「セッション不能状態」を例示する形に統一。

| 項目 | 内容 |
|---|---|
| **修正前** | `セッションに取り組める状態にない（避難・充電・守秘等）` |
| **修正後** | `セッションに取り組める状態にない（急変対応中・他のケア優先・プライバシー配慮が必要な状況等）` |
| **判断理由** | 「充電」は文字化けで、元は「急変」と推測。あわせて「避難」「守秘」も現場文脈に合わせて再構成。 |

## 5. 失敗時のロールバック

`apply_contraindications.py` は実行時に `games-catalog.json.bak` を自動生成する。問題があれば:

```bash
mv games-catalog.json.bak games-catalog.json
python3 scripts/inject_meta.py
python3 scripts/portal.py
```

git レベルで戻したい場合:

```bash
git restore --source=HEAD --staged --worktree games-catalog.json scripts/apply_contraindications.py index.html minatomo-*.html
```

または特定 commit に戻す:

```bash
git reset --hard 41fb010   # 修正前 commit
```

⚠ `git reset --hard` は破壊的なので必ず未 push 状態でのみ使用。
